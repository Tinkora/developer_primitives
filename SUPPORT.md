# Support

## Usage Questions

Search or start a
[GitHub Discussion](https://github.com/Tinkora/developer_primitives/discussions)
for setup help, identifier semantics, and workflow questions.

## Bugs And Feature Requests

Use [GitHub Issues](https://github.com/Tinkora/developer_primitives/issues) for
reproducible bugs and focused feature proposals. Include the project version,
operating system or browser, command or input, expected outcome, actual outcome,
and a minimal reproduction. Remove identifiers or data you cannot share.

The project is community maintained and does not provide a response-time or
support SLA. Clear, reproducible reports are prioritized.

## Security

Do not report vulnerabilities in Issues or Discussions. Follow the private
process in [SECURITY.md](SECURITY.md).
